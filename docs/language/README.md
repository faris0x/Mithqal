# Language documentation

The current language reference is [`latest.md`](latest.md). It describes the
language layer for the current release.

Versioned snapshots preserve the language documented for an earlier release.
The first snapshot is [`language-0.0.1.md`](language-0.0.1.md).

When the language layer changes, copy the current `latest.md` to
`language-<previous-version>.md`, then update `latest.md` for the new release.
The version in the filename is the Mithqal release that introduced that
language layer.

The normative grammar remains in [`spec/`](../../spec/README.md).
