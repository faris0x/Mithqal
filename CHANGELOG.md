# Changelog

## 0.0.1

Initial kernel work.

- Added project documentation for semantics, syntax, the virtual machine, the public API, and the roadmap.
- Added a single crate skeleton.
- Added vendored GMP 6.3.0 and a build script.
- Added exact `Int` and `Rat` wrappers with RAII cleanup.
- Added integer and rational arithmetic tests, including large divisor division.
- Added the hash consed expression arena, symbol table, attributes, and canonical order.
- Added the line based lexer and recursive descent parser, including implicit multiplication, comments, patterns, and exact decimals.
- Added canonical and infix printers with round trip tests.
- Added the exact arithmetic evaluator with listable threading, comparisons, logic, error values, and Gaussian rational normalization.
- Added the public `Session`, `ExprId`, `ExprView`, `Config`, and diagnostic surface.
- Added vendored MPFR and MPC sources with static linking in the build script.
- Added approximate `Real` values with MPFR storage, significance tracking, precision and accuracy reporting, and first order error propagation.
- Added the `approx` numeric boundary with exact rational conversion, `pi` and `e`, arithmetic, powers, roots, exponentials, logarithms, and trigonometric functions.
- Added approximate value views, printing, collection, compiled path support, and numeric tests.
- Renamed the project and crate to Mithqal.
- Added approximate interval arithmetic with addition, multiplication, negation, integer powers, validation, collection support, and tests.
- Added approximate complex arithmetic with a `complex(real,imaginary)` value, `i` recognition in `approx`, addition, multiplication, division, integer powers, reciprocals, absolute value, collection support, compiled path support, and tests.
- Added fast small integer construction for real endpoints and reused real zero and real one values in interval and approximation paths.
- Added all numeric real folding in `plus` and `times`, interval zero power normalization, correct negative interval powers, and shorter precision aware real interning keys.
- Added general real powers through MPFR, complex non-integer powers through MPC, and complex exponential, logarithm, square root, sine, cosine, and tangent functions.
- Added stable scaled complex division, complex power handling, negative real square root and logarithm promotion to complex values, and conservative interval endpoint widening from significance error.
- Added directed MPFR rounding for interval addition, multiplication, negation, and powers, with outward bound selection for products and reciprocals.
- Added binary MPFR interning keys for real values instead of decimal string keys.
- Added real derivative corrections for sine, cosine, and integer powers.
- Added real hyperbolic and inverse hyperbolic functions with derivative based error propagation and domain checks.
- Added complex inverse trigonometric and hyperbolic functions, real domain promotion to complex values, and principal branch orientation for real inverse trigonometric arguments above one.
- Added non finite result rejection for real and complex functions, stable complex magnitude through MPC, allocation free interval multiplication, and numeric head dispatch without per call string allocation.
- Expanded numeric, interval, and complex tests to cover normal values, boundaries, malformed input, errors, precision changes, collection, and the compiled path.
- Added own values, down values, protected symbol checks, definition specificity, and immediate and delayed definitions.
- Added pattern matching for blanks, named patterns, sequence patterns, repeated variables, and conditions.
- Added lexical `let` bindings with local shadowing.
- Added an explicit non moving mark and sweep collector with root tracking, free slot reuse, and intern table rebuilding.
- Added a typed instruction compiler and virtual machine with conditional control flow and a compiled session path.
- Added lexical closures with parameter binding, captured environments, nested closures, and recursive closure calls.
- Added integration tests for numbers, expressions, syntax, printing, evaluation, definitions, patterns, closures, garbage collection, the compiled path, and the session API.
- Added automatic top level collection when the live expression count crosses the configured threshold.
- Optimized hot paths with binary limb keys for interning, FNV hashed maps, hash based like term and base collection, a head resolution fast path, and a release profile with thin LTO and one codegen unit.
- Added parse, compiled code, and definition versioned evaluation caches. Definition changes invalidate the result caches, and collection clears every cache.
- Added constant folding of numeric atoms in the compiler so integer and rational literals avoid an evaluation instruction.
- Added a machine call frame stack that isolates caller and callee operand stack regions for symbol calls.
- Added a benchmark harness for cold parsing, cached evaluation, pattern calls, closure calls, compiled execution, and collection.
- Added exact sparse multivariate polynomial algebra with `expand`, `factor`, `polynomialGcd`, `resultant`, `together`, `cancel`, and `solve`.
- Added rational root factoring, difference of squares patterns, perfect square trinomials, monic univariate gcd, and Sylvester resultants.
- Added exact linear and quadratic solving with rational, irrational, and complex roots.
- Added `==` equation syntax and protected algebra symbols.
- Added polynomial size limits for exponents, expanded term counts, and resultant degree.
- Added lazy algebra head resolution and mutable polynomial accumulation on hot algebra paths.
- Added exact symbolic differentiation for polynomials, products, powers, elementary functions, and inverse functions.
- Added basic exact integration for polynomials, powers, linear substitutions, trigonometric functions, exponentials, logarithms, reciprocal linear terms, and selected inverse function patterns.
- Added definite integration with exact endpoint substitution and symbolic bounds.
- Added calculus simplification through rational cancellation and protected calculus symbols.
- Added a versioned structured IR scaffold with typed arenas, lexical scopes, patterns, definitions, validation, and a builder.
- Added a line-based surface language with lowercase keywords, required modules, single-line definitions, eager bindings, conditionals, print statements, comments, and strict expression whitespace diagnostics.
- Added lexical block scoping, literal parameter patterns, guarded definitions, recursive definitions, and `match`/`case` blocks with literal and binding cases.
- Added exact `gcd`, `lcm`, `factorial`, `binomial`, `floor`, `ceil`, and `round` functions with approximate rounding at the numeric boundary.
- Added exact rational matrix and vector linear algebra with determinants, rank, transposes, inverses, reduced row echelon form, traces, matrix products, identities, unique linear solving, dot products, and cross products.
- Added symbolic matrix entries for determinants, transposes, traces, products, and small inverses, plus PLU factorization and characteristic polynomials.
- Added exact and symbolic two by two eigenvalues, diagonal and triangular eigenvalues, and exact rational null spaces.
- Added broader polynomial algebra with degree, coefficient, polynomial division, discriminants, and sum or difference of cubes factoring.
- Added exact integer number theory with primality testing, next prime, Pollard rho factorization, divisors, Euler totient, divisor sums, parity, divisibility, modular remainder, and modular exponentiation.
- Added broader number theory with previous primes, prime counting, divisor counts, Moebius values, radicals, square-free tests, Fibonacci numbers, perfect square tests, modular inverses, and Jacobi symbols.
- Added exact descriptive statistics with means, medians, extrema, ranges, totals, variances, standard deviations, frequencies, and modes.
- Added boolean `xor`, `implies`, `all`, and `any` with predicate composition.
- Added approximate `gamma`, `lgamma`, `erf`, and `erfc` functions through MPFR.
- Added a fast whitespace-free atom parser, two-integer operation parser, integer list evaluation shortcut, integer statistics paths, tiered Miller-Rabin, unified kernel dispatch, top-level integer arithmetic folding, and arena-cached kernel head handles.
- Expanded the suite to more than 490 test functions and more than 1300 assertion sites, plus generated arithmetic, parser, numeric, language, linear algebra, number theory, statistics, and logic corpora.
